HOW IT WORKS

A camera with a commit button.

01Capture locally

The browser opens your device camera. The photo stays in memory until you approve it.

02Review once

You get one clear chance to discard or send the staged image.

03Write direct

A GitHub Contents API request creates the file in your chosen repository.

Privacy note

There is no Snapline server. GitHub sees your request, and your browser keeps the local connection settings.
