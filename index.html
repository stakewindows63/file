This site uses a private Netlify Function to talk to GitHub. The browser never receives a GitHub token, so visitors can upload without configuring an account.

Credential protected by deployment

HOW IT WORKS

A camera with a commit button.

01Capture locally

The browser opens your device camera. The photo stays in memory until you approve it.

02Review once

You get one clear chance to discard or send the staged image.

03Write direct

A GitHub Contents API request creates the file in your chosen repository.

Privacy note

The upload function forwards the approved image to GitHub. The GitHub credential stays in Netlify and is never sent to the browser.
